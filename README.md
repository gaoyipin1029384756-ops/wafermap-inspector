# 🔬 WaferMap Inspector

基于深度学习的晶圆缺陷智能检测系统。

## 📋 项目简介

本项目针对半导体制造中的晶圆缺陷检测问题，使用 **卷积神经网络（CNN）** 对晶圆缺陷图谱进行自动分类。系统可识别 **9 种缺陷模式**，包括 Center、Donut、Edge-Loc、Edge-Ring、Loc、Random、Scratch、Near-full 等。

**技术栈：** PyTorch + Streamlit + Python

**适用场景：** 微电子专业学习、AI 训练实践
